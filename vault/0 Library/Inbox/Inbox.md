# Inbox

> **What this is** : everything waiting to be read. The Economist adds the papers it cites that are not in the library yet, and you can drop anything by hand.
> **Open it** : at the start of a reading slot.
> **Rule** : an item leaves the Inbox with a decision. `[x]` read, `[>]` keep for later, `[-]` skipped with a reason, `[?]` candidate source.

**Add by hand** : paste a line `- [ ] [title](link) · why it caught your eye` under *Added by hand*. For a PDF or a letter you received, put the file in this folder and add a line with `[[file name]]`.
