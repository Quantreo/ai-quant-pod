# AI Quant Pod : research vault

The shared memory of your pod. Every agent reads and writes here, and so do you.

**Open it**: in Obsidian, *File → Open folder as vault*, and choose this `vault` folder. Come back to this page whenever you are lost.

The folders appear as you build the pod, section by section.

## The flow

```
 0 Library  →  1 Ideas  →  2 Strategies  →  4 Book
 papers,       the Idea     one folder per    the strategies
 notes,        Journal      strategy: Pass 1, you run, and
 techniques                 build, Pass 2,    their weights
                            test, report
                                 ↓
                          3 Research Log
                          every run, every try
```

## The folders

- **`0 Library/`**: what the pod knows. `Sources/` (the PDFs, never pushed to GitHub), `Notes/` (one faithful reading note per source, with pages), `Techniques/` (one card per reusable technique, filed by brick), `Inbox/` (papers and posts waiting to be read, and the Scout log).
- **`1 Ideas/`**: the Idea Journal, one entry per idea, written by the Ideator from the library.
- **`2 Strategies/`**: one folder per strategy. The folder is the status: `Pipeline/` (in progress), `Passed/` (passed the sealed test), `Killed/` (with the reason). The register is `_Index.md`.
- **`3 Research Log/`**: every run and every try, the luck line, the lessons, and the desk's reports.
- **`4 Book/`**: the book, what the whole pod works for.

## The toolbox

- **`Toolbox/`**: the reference the agents and you open while you work: tags, sources, costs, defaults, kill policy, glossary.
- **`Templates/`**: blank reading note, strategy sheet, checklist, monitoring note.

## The rule behind everything

Write what you expect before you look at the result. Every note in this vault exists to make that possible.
